# CloudServe Intelligent Support System — pinned dependencies

# NOTE ON DEVIATION FROM THE CAPSTONE PACK
# The pack's 06_Configuration/requirements.txt cannot be installed. It pins
# langchain-openai==0.0.7 (which requires openai>=1.10) against openai==1.0.0,
# and pip returns ResolutionImpossible. It also pins sentence-transformers==2.2.2,
# which fails at import against modern huggingface_hub. Following it literally
# fails at acceptance criterion A1. This file is the verified replacement; every
# pin below was resolved together in a clean virtual environment on Python 3.11.
#
# Embeddings note: we deliberately do NOT install sentence-transformers or torch.
# chromadb ships onnxruntime and its built-in embedding function is
# all-MiniLM-L6-v2 — the exact model the Project Brief specifies — so we get the
# required model without a ~2.5 GB torch dependency. This keeps the clean-checkout
# install small and fast, which directly serves A1.
